# WISER Method

The WISER Method is an open method for operationalizing AI. It has five canons (Witness, Interrogate, Solve, Expand and Refine), with plays, playbooks and positions, and it is built on [AI First Principles](https://aifirstprinciples.org) and organizational AGI.

It is stewarded by [EffectiveSC](https://effectivesc.org), a 501(c)(3) public charity, and published under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

- **The method:** [wisermethod/wiser-method](https://github.com/wisermethod/wiser-method)
- **Website:** [wisermethod.com](https://www.wisermethod.com)
